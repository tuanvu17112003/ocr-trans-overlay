## OCRTrans v0.1.0 — bản đóng gói đầu tiên

Dịch phụ đề / văn bản tiếng Anh sang tiếng Việt ngay trên màn hình, dùng overlay
click-through mà công cụ chụp màn hình không thấy.

### Tải về

**`OCRTrans-0.1.0-win64-cpu.zip`** (330 MB) — không cần Python, không cần NVIDIA.

1. Giải nén ra chỗ bất kỳ (ví dụ `D:\\OCRTrans`)
2. Chạy `OCRTrans.exe`
3. `Add region` → kéo chọn vùng có chữ cần dịch
4. Chọn engine → `Start`

Phím tắt: `Ctrl+Alt+Z` bật/tắt · `Ctrl+Alt+R` thêm vùng · `Ctrl+Alt+H` HUD · `Ctrl+Alt+Q` thoát.

### Bản này là CPU-only

| Thành phần | Bản portable (CPU) | Bản cài từ mã nguồn (GPU) |
|---|---|---|
| OCR | onnxruntime CPU, ~1–2 pass/giây | RapidOCR + CUDA |
| Dịch offline | Argos (tải gói ngôn ngữ ~100 MB lần đầu) | NLLB-600M + EnViT5 + Argos |
| Dung lượng | 930 MB (zip 330 MB) | ~3 GB wheel |
| Yêu cầu | Windows 10/11 x64 | + NVIDIA GPU + CUDA 13 driver |

Bản CUDA **không** đóng gói được: `torch+cu130` riêng đã ~2.9 GB, vượt giới hạn
2 GB mỗi file của GitHub Release. Máy có GPU nên cài từ mã nguồn (`install.ps1`)
vừa nhanh hơn vừa nhẹ hơn.
